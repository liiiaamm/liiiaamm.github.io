# liiiaamm.github.io

Personal website of Liam Esgueva: [liiiaamm.github.io](https://liiiaamm.github.io).

Plain HTML, CSS and JavaScript, no build step. Every illustration is drawn in code: the contour map in the header is a loss landscape you can drop balls into, and each project card borrows the look of its own interactive demo.

To add a project, add an entry to the `P` array in `assets/site.js`.

```bash
python -m http.server 8000
```
